## 🎮 การเปิดและทดสอบโปรเจกต์ใน Unity Editor
1. เปิดโปรแกรม **Unity Hub**
2. เลือก **Add** ➔ เลือกโฟลเดอร์โปรเจกต์นี้ (`c:\CaDaCooked\CaDaCookedScripts`)
3. ใช้ **Unity 6000.3.6f1** (หรือเวอร์ชัน Unity 6 ที่เข้ากันได้)
4. เปิดฉาก **`Assets/Scenes/MainMenuScene.unity`** หรือ **`Assets/Scenes/GameScene.unity`**
5. กดปุ่ม **Play** เพื่อเริ่มเล่นเกม
